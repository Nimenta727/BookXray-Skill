# Independent quality rubric

## Deterministic gate (implemented)

The audit command checks: source hash; packet/source coverage; packet offsets; agent unit IDs; section IDs; minimal explanations; source attribution; quote character offsets; PDF page claims when page mapping exists; and at least one valid cited unit in each nonempty section. Invalid citations block export.

## Semantic and educational audit (human or separate model; NOT yet automated)

For each chapter, independently inventory all essential concepts and examples against the original. Record omissions, misleading compression, unsupported generalization, false causal claims, missing edge cases and misattributed viewpoints. Verify mathematical derivations, code, charts and translations in their original representations. Grade groundedness and teaching usefulness separately.

Sampling is not proof of total coverage. A gold inventory created independently of the generator is required for concept recall. Aggregate only observed evidence; never fabricate scores. Prefer actionable finding records: section, expected idea, observed defect, supporting source location, severity, proposed repair, reviewer ID.
