# Analysis strategies / 书籍分析策略

Before analyzing, classify the book using evidence from its metadata, TOC and content; do not infer a discipline solely from a filename. The selected CLI profile is user preference, not an automated truth claim.

- **Textbook**: define learning objectives and prerequisites, explain each idea, derive formulas if present, include worked **original** examples, typical misconceptions, exercises with explanations and chapter dependencies. Do not equate page count or word count with pedagogical depth.
- **Technical/programming**: language/framework version, runnable code where appropriate, interfaces, constraints, debugging, edge cases, tests and operational security.
- **Academic/research**: research question, definitions, methods, main claims, exact evidence, uncertainty, competing interpretations, limitations; separate evidence from conjecture.
- **History/social science**: timelines, actors, primary/secondary sources, causal and alternative explanations, historiographic disputes.
- **Philosophy**: definitions, premises, inference chains, counterarguments, and strongest charitable interpretation.
- **Literature**: genre, plot development, characterization, narrator, structure, motifs and alternative interpretations; respect spoiler preferences.
- **Business/management**: frameworks, assumptions, original applications, prerequisites, counterexamples, transferability and measurable outcomes.

For mixed works, apply multiple strategies by section. The result should be a teaching/research aid, not a replacement for reading a copyrighted book. Cite verified source offsets for every major unit.
